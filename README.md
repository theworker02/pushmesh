# pushmesh

Push HTML/Markdown mesh fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/pushmesh/

## Install / run

```bash
git clone https://github.com/theworker02/pushmesh.git
cd pushmesh
node src/cli.js
node --test
```
